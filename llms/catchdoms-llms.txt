# CatchDoms

> Expired domain finder that aggregates 20+ registrars, drop-catchers, marketplaces, and domain databases, enriches domains with SEO metrics, and scores them 0-100. Includes a REST API and MCP server for AI assistants.

CatchDoms pulls expiring, auction, brandable, pending-delete, and deleted domains from more than 20 sources. Each domain can include Trust Flow, Citation Flow, Domain Authority, backlinks, referring domains, Wayback Machine history, language detection, historical technology signals, organic-traffic estimates, and Google Business Profile data. A scoring algorithm (0-100) with spam detection surfaces the best domains quickly.

The Aged Domains database contains deleted domains across roughly 80 ccTLDs that remain available for registration at standard registrar prices, with no auction required.

The Pending Delete database tracks actionable ccTLD and gTLD domains before they drop, including pendingDelete, redemptionPeriod, serverHold, clientHold, transition, and quarantine states, with estimated drop dates where available.

Authority unlocks the Aged Domains deleted-ccTLD inventory. Authority+ includes Authority access and additionally unlocks the Pending Delete inventory.

Built for SEO professionals, domain investors, and digital agencies.

## Price Currencies

REST and MCP domain responses include `currency`, the ISO 4217 code applying to the raw `price`, `max_bid`, `effective_price`, `estibot_appraisal`, and `renewal_price` values. Amounts are not converted; price filters compare each source's native amounts.

- USD: Dynadot, Catched, DropCatch, GoDaddy, Gname, SnapNames, Park.io, NameSilo, Namecheap, SEO.Domains, NamePros
- EUR: Subreg, WebExpire, BloomUp, Nicsell, Sedo, Gnews Domains, Backorders Domains
- GBP: UKDroplists, DomainLore
- JPY: Rakko
- `null`: NameShift and Aged Domains (Regfree), because their import paths do not have one deterministic source currency; Pending Delete has no price fields
